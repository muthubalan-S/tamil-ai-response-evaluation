# Tamil AI Response Evaluation Dataset

## Project Overview

This project is a Tamil-language AI response evaluation and data annotation dataset created to demonstrate skills related to AI data labeling, response evaluation, and data quality assessment.

The dataset contains 50 Tamil questions with two AI-generated responses for each question. The responses are evaluated and labeled based on their correctness and quality.

## Dataset Structure

The dataset contains the following fields:

| Column         | Description                                   |
| -------------- | --------------------------------------------- |
| ID             | Unique identification number for each example |
| Tamil Question | Question written in Tamil                     |
| AI Answer A    | First AI-generated response                   |
| AI Answer B    | Second AI-generated response                  |
| Correctness A  | Evaluation label for Answer A                 |
| Correctness B  | Evaluation label for Answer B                 |
| Better Answer  | The response selected as better               |
| Reason         | Explanation for the evaluation decision       |

## Annotation Labels

### Correct

The response is factually accurate and directly answers the question.

### Incorrect

The response contains false or misleading information.

### Partially Correct

The response contains some correct information but is incomplete or partly inaccurate.

### Unclear

The response does not provide a meaningful or understandable answer.
